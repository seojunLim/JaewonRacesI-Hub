UNITY 개발 전 · 재미 검증 프로토타입

에테르 Z+ : 세계의 법칙 기획서 33장 「프로토타입에서 반드시 검증할 것」 5개 항목을 직접 만져 보는 3D 플레이어블 테스트

완성된 게임이 아니라 가설 검증 장치다. 3인칭 3D로, 무게 · 위상 · 관성 세 법칙과 Z + 계열키 + 행동키 입력 구조, 그리고 발동 순간의 감각을 기획서 그대로 구현했다. 챔버마다 검증 항목이 하나씩 붙어 있고, 끝나면 자동 계측과 자기 평가가 담긴 리포트가 나온다.

Z + Q / E / R무게 / 위상 / 관성 계열
Z + 계열 + 좌·우클릭세부 능력 (화면 중앙 조준점으로 조준)
Z + 계열 + E / Shift3·4번째 능력 (이동 / 저장 / 자기 대상)

키보드 + 마우스 전용. WebGL2를 지원하는 데스크톱 브라우저에서 동작한다.
SJL Engine(github.com/seojunLim/SJL-GAME-ENGINE)으로 만들었다. 게임 로직은 scenes/*.json 과 src/*.js 에 있고, node --test 로 모든 챔버의 해법이 헤드리스로 검증된다.
